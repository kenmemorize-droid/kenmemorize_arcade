HexaSum

Memorize the board, then find 3 hexagons in a straight line that add up to the target number
How to Play

Memorize the number inside every hexagon before time runs out. When the timer ends, the numbers flip face-down and only letters remain.

Select 3 hexagons in a straight line whose numbers add up to the target sum shown above the board.

Solo: find as many valid lines as you can. Pass & Play: take turns — first to 5 points wins.
